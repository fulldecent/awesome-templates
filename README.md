# Awesome templates

Starting points for a new project. Use the [project template](https://github.com/fulldecent/project-template) unless a more specific template applies. [![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome)

A GitHub template repository is what puts **Use this template** on the repository page. The steps are in [Creating a template repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository).

## Contents

* [fulldecent](#fulldecent)
* [PHP](#php)

## fulldecent

* [Project template](https://github.com/fulldecent/project-template) - Every project, unless a more specific template applies.
* [Node.js template](https://github.com/fulldecent/node.js-template) - Node.js modules (e.g. on NPM) and applications.
* [Rust template](https://github.com/fulldecent/rust-template) - Every Rust project. The **Use this template** button is off, so copy the repository.
  * [Zellij plugin template](https://github.com/fulldecent/zellij-plugin-template) - Every Zellij plugin.
* [GitHub Pages template](https://github.com/fulldecent/github-pages-template) - Collaboratively-edited HTML websites.
  * [GitHub Pages Eleventy template](https://github.com/fulldecent/github-pages-eleventy-template) - Discussion draft for an Eleventy website.
* [Swift 6 module template](https://github.com/fulldecent/swift6-module-template) - Reusable Swift 6 modules.
* [Solidity template](https://github.com/fulldecent/solidity-template) - Solidity contracts (technology preview).
* [Moodle plugin template](https://github.com/fulldecent/moodle-local_plugin_template) - Moodle plugin (work in progress).
* [Podcast template](https://github.com/fulldecent/podcast-template) - Podcast on your own domain.

### Archived

* [Pod template](https://github.com/fulldecent/pod-template) - A CocoaPods pod.
* [Objective-C module template](https://github.com/fulldecent/objective-c-module-template) - Reusable Objective-C modules.

## PHP

* [thephpleague/skeleton](https://github.com/thephpleague/skeleton) - Skeleton for packages from The PHP League. Recommended by the author of [PHP The Right Way](https://phptherightway.com/) in [this post](https://twitter.com/philsturgeon/status/1184854558176169985).
* [ergebnis/php-package-template](https://github.com/ergebnis/php-package-template) - Composer package with GitHub Actions and the standard PHP tools. This is the maintained continuation of `localheinz/php-library-template`.
